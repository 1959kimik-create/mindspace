# MindSpace

로그인 없이 바로 명상할 수 있는 단일 페이지 웹앱입니다. 시간대에 맞는 배경에서 타이머를 켜고, 수면·집중·휴식·자연의 소리 영상을 들으며, 완료 기록을 달력으로 확인합니다.

## 기능

- **시간대 테마**: 기기 시각으로 아침 / 낮 / 저녁 / 밤 / 새벽을 자동 적용하고, 상단에서 직접 바꿀 수 있습니다.
- **명상 타이머**: 3분, 5분, 10분, 15분, 자율. 끝나면 알람과 완료 모달이 뜹니다.
- **명상 영상**: 수면(밤 빗소리), 집중, 휴식 BGM, 실제 파도 소리를 페이지 안에서 재생합니다.
- **챌린지 달력**: 완료 기록을 브라우저 LocalStorage에 저장하고, 해당 날짜에 스탬프와 총 명상 시간을 보여줍니다.

브라우저 쿠키나 방문 기록을 지우면 달력 기록이 사라질 수 있습니다.

## 실행 방법

유튜브 임베드는 `file://`로 HTML을 직접 열면 재생되지 않을 수 있습니다. 로컬 서버로 열어 주세요.

```bash
npx serve -l 5173
```

브라우저에서 [http://127.0.0.1:5173/](http://127.0.0.1:5173/) 로 접속합니다.

## 기술

Vanilla HTML, CSS, JavaScript만 사용합니다. 별도 프레임워크나 백엔드는 없습니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 다크 글래스모피즘 스타일 |
| `app.js` | 테마, 타이머, 유튜브, 달력 |
